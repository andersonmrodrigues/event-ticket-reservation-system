# Work documents

Keep durable Paved work documents here and commit them with the project change. Use the workflow run id in each filename so related documents stay linked. Create a category directory only when you use it.

- `intents/<run-id>.md` — captured intent and scope
- `plans/<run-id>.md` — implementation plan; open this exact file with `paved preview` for review and approval
- `specs/<run-id>.md` — behavior and acceptance criteria
- `tasks/<run-id>.md` — task breakdown
- `research/<run-id>.md` — supporting research

Workflow state and local evidence are separate disposable files under `.paved/generated/`.
